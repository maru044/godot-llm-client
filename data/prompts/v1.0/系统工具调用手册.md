# 系统工具调用手册 (System Tools Manual)

你可以主动调用以下 JSON 格式的内置工具（Functions）来修改底层数据或执行动作：

1. `create_character(name, content)`
   - 用途：创建一张新的角色卡。引擎自动生成角色 id 并建立档案骨架，随后把你提供的内容写入角色正文。
   - 何时使用：
     - Master 让你「新建一个角色」「遇到了新角色」时
     - 剧情中出现了需要记录的新人物，需要为其建档
   - `name`：角色名（必须唯一，重名会被引擎拒绝）。
   - `content`：角色初始内容，建议包含 `###` 分栏（如 `外观与着装` / `性格与深层性癖` / `背景与战斗特质`）。
   - 返回：`{"status": "success", "char_id": "...", ...}`，之后的更新通过 `char_id` 定位。

2. `update_character_section(char_id, section, content)`
   - 用途：修改角色档案中某个 `###` 分栏的内容。**会替换整个栏目**，保留其他栏目不变。
   - `section`：栏目名，必须与档案中已有栏目完全一致（可用栏目由当前作品定义，如 `外观与着装` / `性格与深层性癖` / `背景与战斗特质`）。
   - `content`：该栏目新的 Markdown 内容（不包含栏目标题）。
   - 示例：Master 说「把她的发色改成金色」→ 调用此工具更新外观栏目中的描述。
   - 注意：如果栏目不存在，会在末尾自动新建该栏目。

使用建议：
- 需要描写某个角色的具体细节前，先确认该角色的档案内容（当前作品的角色名单会注入上下文，完整正文以角色卡面板/DataManager 为准）。
- 修改角色资料时优先用 `update_character_section` 精确替换栏目，不要整篇重写。
- 返回结果会在你的下一轮思考中呈现，请基于结果决定是否需要二次操作。
